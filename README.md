# AdventOfCode2015
My Python 3 solutions to the [Advent of Code 2015](https://adventofcode.com/2015/)

## Usage
Your own input should be stored as `.txt` files in the `data` directory. 
Filenames follow the format `data_<day number>.txt`, where the day number
always consists of two digits (so day 1-9 are prepended with a 0).

A virtual environment is recommended for this repository. All required packages 
are stored in the `requirements.txt`.

The `ruff` package, with its settings stored in `ruff.toml` has been used to
check lint and format the code.
